# liuyao-divination · 皇极二元 × 尚氏象数六爻解卦技能

一套专为 AI Agent（Antigravity / Claude Code / Cursor / Codex 等）打造的确定性**六爻纳甲排盘与古典象数解卦 Skill**。  
通过 Python 确定性排盘消除大模型“算错干支、排错六亲、算错动爻”的幻觉，并内置 7 部高纯度 Markdown 易学典籍按门类按需检索，融合**贾秉然“皇极六爻二元兼象定论”**、**尚秉和“八卦互体正象取象法”**与**明宋元古法三经总纲**，实现严谨、可溯源的分类解卦。

---

## 核心特性

1. **五要素极简输入，动爻自动算出**：只需提供 `本卦`、`变卦`（无变卦即为静卦）、`公历时间`、`所问何事`、`性别`，脚本自动对照本卦与变卦阴阳爻位算出动爻。
2. **零幻觉确定性排盘 (`scripts/paipan.py`)**：
   - 基于 `lunar_python` 精确换算节气月建、日辰、时辰、旬空、月破；
   - 自动配全八宫世应、六神、伏神（含飞伏生克五法）、变卦本宫六亲、化进退/回头生克/墓绝空破；
   - 自动提取皇极兼象坐标（**卦身、世身、子孙胎爻**）与尚氏象数坐标（**二至四/三至五互体卦、反对倒体卦**）。
3. **分类按章查库 (`scripts/query_corpus.py`)**：按财运/投资、官运、考试、婚姻、孕产、出行/失踪、遗失/捕盗、疾病/灾祸、民刑诉讼等门类精准检索 `references/` 下的对应章节。
4. **单问 / 多问并发拆解**：支持用户一次问多件事，逐问切换用神、查章立极，并在盘面双元受克时自动触发“占此应彼”隐患预警。

```bash

```

## 使用示例

### 1. 对话直接触发（推荐）

向已加载本技能的 AI 发送如下 5 项信息即可（无变卦可省略或写“静卦”）：

> 帮我用六爻解卦：男性，公历 2026-11-26 14:35，本卦**天地否**，变卦**天山遁**。我想问两件事：
> 1. 最近和朋友合伙投资开餐饮店，能不能成、赚不赚钱？
> 2. 顺便看看今年感情婚姻顺不顺利？

### 2. 命令行独立调试脚本

```bash
# 1) 自动排盘（支持全名或简称如“否/遁”；无变卦或 --bian 无 即自动按静卦处理）
python scripts/paipan.py \
  --ben "天地否" \
  --bian "天山遁" \
  --time "2026-11-26 14:35" \
  --gender "男" \
  --question "测合伙投资开餐饮店，兼问感情走向"

# 2) 按门类检索语料对应章节
python scripts/query_corpus.py --category "投资" --max-chars 1200

# 3) 按指定典籍与关键词检索
python scripts/query_corpus.py --book "古筮" --query "魏管辂为刘邠射覆"
```
